# Kaxa Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Kaxa marketing website (landing + legal/support pages, ES/EN) per `docs/superpowers/specs/2026-06-10-kaxa-website.md`.

**Architecture:** Astro static site (`output: 'static'`) with Tailwind CSS v4 (via `@tailwindcss/vite`), Nunito font via `@fontsource/nunito`. Bilingual via hand-written translation objects (no i18n routing plugin) — ES pages live at the root (`/`, `/privacidad`, `/terminos`, `/soporte`), EN pages live under `/en/` (`/en/`, `/en/privacy`, `/en/terms`, `/en/support`). Shared Astro components receive a `lang` prop and pull strings from `src/i18n/translations.ts`.

**Tech Stack:** Astro 5, Tailwind CSS v4, `@fontsource/nunito`, `@astrojs/sitemap`, Vitest + Astro Container API for component tests. Deployed to Vercel as a static site, domain `kaxa.lat`.

**Project location:** new directory `website/` at the repo root (sibling to `kaxa/`). All commands below assume `cwd = website/` unless stated otherwise.

Create `website/src/i18n/routes.ts`:

```ts
export type Lang = 'es' | 'en';

export const routes = {
  home: { es: '/', en: '/en/' },
  privacy: { es: '/privacidad/', en: '/en/privacy/' },
  terms: { es: '/terminos/', en: '/en/terms/' },
  support: { es: '/soporte/', en: '/en/support/' },
} as const;

export type RouteKey = keyof typeof routes;

export function otherLang(lang: Lang): Lang {
  return lang === 'es' ? 'en' : 'es';
}
```
